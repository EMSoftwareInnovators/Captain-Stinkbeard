# Gameplay overhaul: audit and plan

Planning documents for the Captain Stinkbeard gameplay overhaul. Prompt 1 was the audit (documents 00–05); Prompt 2 built the regression harness and measurement baseline (document 06); Prompt 3 added challenge outcomes, checkpoints and retries as opt-in infrastructure (document 07); Prompt 4 added difficulty modes, accessibility assists and their settings on top of it (document 08); Prompt 5 gave the ship a condition: structural sections, damage, and material repairs played as challenges (document 09); Prompt 6 added leaks, flooding, fire and the emergency response on top of it (document 10); Prompt 7 gave the ship real air, room by room, with ventilation, containment and the captain's exposure (document 11); Prompt 8 added Grand Stenchmaster pressure: Brogath and Garrick building up, the captain's interventions, and eruptions that pour into the air, blow doors and strike the hull (document 12); Prompt 9 made the captain's Stink Beard a filter and a store: it soaks up gas, saturates, protects less, purges, takes on conditions and can be cared for at the washroom tub (document 13). None of them changed how the existing campaign plays.
