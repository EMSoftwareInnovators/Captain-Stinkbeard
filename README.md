# Captain Stinkbeard

A retro 16-bit-style pirate RPG for the web, built with **Phaser 4**, plain
JavaScript ES modules and **Vite**. This repository contains **Phase 1** (the
engine foundation and a playable prologue aboard Blackbeard's ship, the
*Revenge*, about 10–20 minutes), **Story Phase 2: Garrick Guzzlegut and the
Cursed Treasure**, eight chapters that continue straight on from the prologue
(about 30–60 minutes), **Story Phase 3: The Grand Stenchmaster**, six more
chapters that pick up the same evening (about 45–75 minutes), and **Story
Phase 4: Life Around the Dead Center**, five chapters of the crew trying to
live with a wandering stench cloud and the sharks it brings (about 45–75
minutes), and **Story Phase 5: What Does the Grand Stenchmaster Actually
Do?**, five chapters in which the crew finally ask (about 35–60 minutes).

Every pixel and every note is original and generated by code at startup: there
are no downloaded sprite sheets, fonts, samples or music files. The game needs
no backend and no paid services; saves live in browser storage.

---

## Quick start

```bash
npm install
npm run dev        # http://localhost:5173 (debug overlay on F2)
npm run build      # production build in dist/ (debug tools stripped)
npm run preview    # serve dist/ at http://localhost:4173
```

Other scripts:

| Script | What it does |
| --- | --- |
| `npm test` | Unit tests (Vitest): systems, battle math, scripts, saves, content, balance |
| `npm run validate` | Content validation only (cross-references every data file) |
| `npm run e2e` | Plays the prologue and Story Phases 2, 3 and 4 in headless Chromium (Playwright), keyboard and simulated controllers (about 40 minutes). Run `npx playwright install chromium` once, or set `CHROMIUM_PATH` |
| `npm run e2e:smoke` | The quick browser checks (a few minutes) |
| `npm run e2e:quick` | Every browser test except the long story playthroughs |
| `npm run e2e:story` | Only the story playthroughs. Any tag works too: `npm run e2e -- --grep @phase3` (see [ARCHITECTURE.md](docs/ARCHITECTURE.md#testing)) |
| `npm run export` | Writes all generated art to `exports/sprites/*.png` and the maps to Tiled `exports/tiled/*.tmj` |

Node 20+ is recommended.

## Controls

Keyboard and gamepad work everywhere; no mouse is needed. On-screen prompts
switch automatically between keyboard and controller glyphs.

| Action | Keyboard | Gamepad (Xbox names) |
| --- | --- | --- |
| Move | Arrow keys / WASD | D-pad / left stick |
| Talk, inspect, confirm | Z, Enter, Space | A (south) |
| Cancel, back | X, Esc, Backspace | B (east) |
| Run (hold) | Shift (or X) | B / X (west) |
| Pause menu | C, Esc | Y (north), Start |
| Switch tabs | Q / E, Page Up / Page Down | LB / RB |
| Debug overlay (dev builds) | F2 | — |

Controllers are read by button *position*, whether or not the browser maps
them to the standard layout, and a toast says "Controller ready" the first
time a pad is readable.

**Controller setup.** Some browsers hand a pad over with its buttons in
places the game can't guess. The usual case is an Xbox pad over Bluetooth in
Firefox on a Mac, where A, B, X and Y do nothing even though the prompts
switch. Such a pad gets **Options > Controller**, which asks you to press
each button in turn and remembers the layout for that controller:
- it opens by itself the first time you press a button on a pad the browser
  doesn't map. In Firefox it also opens for a pad Firefox calls standard
  (Firefox can report a shifted pad that way): press A, then B, and if
  they're right the check ends there;
- a D-pad that reports as a hat switch works too;
- skip a step with the pad's A (once learned), Enter, or by waiting;
- in Options, Left on the Controller row forgets a learned layout.

In development builds the F2 *Info* tab shows what each pad reports.

**Never stuck behind people.** Walk into someone who's in your way for a
moment and you squeeze past them. After a scene, the crew make their way to
wherever the story has them next.

In battle, choose commands with the direction buttons and confirm. When
Blackbeard swings his cutlass, a white ring closes on the target: press
confirm as it meets the gold ring for a **GOOD / GREAT / PERFECT** hit. When an
enemy lunges at you, press confirm as the blow lands to **guard**. Neither is
required; they just make fights shorter and safer.

**Options and accessibility** (title screen or pause menu): volumes, text
speed and sounds, always run, **Screen shake** (Full / Reduced / Off),
**Visual effects** (Full / Reduced: fewer particles, softer flashes, calmer
fumes), **Fume hazard** (Normal / Gentle / Off: how fast thick fumes build
up), scaling and fullscreen. Dialogue moves to the top of the screen whenever
it would cover the people talking.

## What's in Phase 1

- **Blackbeard's ship**: Main Deck, Captain's Quarters, Crew Quarters, Galley,
  Cargo Hold and Treasure Hold, with an animated ocean swell, flag and
  lantern animation, gulls, chimney smoke, crew routines and baked lighting.
- **11 crew members** with portraits, several expressions and conditional
  dialogue; Blackbeard himself as the player character.
- **Quests**: *Captain's Rounds*, *Rats in the Hold* and the side quest
  *A Match for Brask*, plus a returnable item for Old Finch and a sparring match
  with Rook.
- **Turn-based battles** against visible enemies (no random encounters) with
  back-attack advantage both ways, timed hits, guarding, items, **Captain's
  Orders** (BRACE! and FOCUS FIRE!), statuses, summons, XP, gold and drops.
- Title screen, options, pause menu (Status, Items, Equip, Quests, Options,
  Save), shops, three save slots plus autosave, game over with retry.

## What's in Story Phase 2

*Garrick Guzzlegut and the Cursed Treasure.* Sleep in the captain's bed after
the prologue to begin. A peaceful morning on the Sapphire Sea ends when One-Eyed
Ned spots a man paddling a bathtub with two giant sausages: Garrick Guzzlegut,
disgraced dockside treasure appraiser and self-described maritime
businessman. He joins the crew (provisionally), turns the foredeck into a toll
road, eats a catastrophic lunch, and is taken to help in the treasure room.
What follows is the Guzzlegut Gust, a yellow cloud through the whole ship, a
rescue in the Dead Center, a ruined fortune, a trial, and a royal frigate.

- **Eight chapters** with cutscenes, illustrated vistas (the telescope view,
  the ship from afar, the figurehead, the frigate, an epilogue montage) and
  close-up inserts, and attitude choices that converge.
- **Seven quests**: *Strange Cargo*, *The New Recruit*, *Treasure Inspection*,
  *Yellow Alert*, *Save Squawks*, *The Price of Gold*, *The Yellow Defense*.
- **New characters**: Garrick Guzzlegut, Captain Squawks (normal, exposed,
  bald and sweater looks), Salty Jim, One-Eyed Ned, Barnacle Bob and the
  prisoner-merchant Penhallow; crew dialogue for every stage of the day.
- **Fume hazard**: light, dense and Dead Center zones, drifting pockets, an
  exposure meter, never-fatal collapse (Rook hauls you out), and a *Fume
  hazard* option (Normal / Gentle / Off).
- A playable rescue with a trailing rope, a naval set-piece at the helm, and
  permanent consequences: ruined treasure, stained boots, a bald parrot and a
  rowboat protocol.
- Nine new music tracks, new ambience beds and about fifty new sound effects,
  all synthesised in code.

See [docs/STORY_PHASE2.md](docs/STORY_PHASE2.md) for the chapter-by-chapter
flow, flags and where everything lives.

## What's in Story Phase 3

*The Grand Stenchmaster.* It continues the same evening Phase 2 ends. Garrick
decides the day's events qualify him for a promotion, invents the title
*Grand Stenchmaster of the Seven Seas*, and starts keeping a Stench Log.
Blackbeard smells his own beard and becomes **Captain Stinkbeard**, the
ship's drink becomes **Frog Grog**, the ship itself starts to change, and
Garrick's emissions bring the sharks. His solution works, unfortunately.

- **Six chapters** (9 to 14) and **six quests**: *A Necessary Promotion?*,
  *What Did You Call Me?*, *Frog Grog*, *The Ship Is Changing*, *Sharks!*,
  *Grand Stenchmaster, Temporarily*.
- **The rename**: the captain's name follows the story everywhere (name
  plates, status, save slots, quest text, crew dialogue). Old saves keep
  working.
- **The Stench Log**: a data-driven logbook in the pause menu (location,
  severity, probable source, notes) that fills in as the ship changes.
- **Frog Grog**: a consumable that heals, slows fume build-up for a while,
  and has one small random side effect.
- **Sharks**: a reusable threat layer (curious, following, attacking,
  swarm), a hull breach to patch in a timing game, a shark that follows your
  beard, one that lands on deck, and a rowboat lure.
- A changed ship that stays changed: yellowed wood, breathing sails,
  sweating ropes, a coughing bell, a masked rat, and a parrot with one new
  yellow feather.
- Four new music tracks (a Grand Stenchmaster fanfare and theme, a Frog Grog
  shanty, a shark attack cue), rain and shark ambience, and about thirty new
  sound effects.

See [docs/STORY_PHASE3.md](docs/STORY_PHASE3.md) for the flow, flags and
systems.

## What's in Story Phase 4

*Life Around the Dead Center.* The captain goes to bed at the end of Phase 3
and wakes into the new normal: Frog Grog every morning, a crayon forecast
from the Grand Stenchmaster (now in a sash he made himself), and the Dead
Center wandering the ship, always choosing exactly the room that's needed.

- **Five chapters** (15 to 19) and **six quests**: *Today's Forecast*,
  *Life Around the Center*, *The Worst Places*, *Seven Feathers*,
  *Shark Duty*, *Repair It Again*.
- **The Dead Center moves**: eleven places in data (breakfast, the washroom,
  the stove, the sleeping quarters, the deck camp at 3 AM, the quarterdeck,
  the captain's cabin, the waterline...). It rolls in with time to get out,
  and the rooms it fills stay shut until it moves on.
- **The bell protocol**: one to four coughing bells, always shown in words
  as well as heard.
- **The Forecast Board**: every crayon forecast, pinned up on deck and in the
  pause menu, with risk, confidence, what actually happened, and each map.
- **Shark Duty**: a real job on the rail with a pole; sharks come one wave
  at a time, you face the rail and shove them off; bites leave damage to
  patch. Twenty to port, thirty to starboard, then HUNDREDS; a frenzy at the
  waterline; a hammerhead; the ship getting smaller. After the phase Jory
  will give you a shift whenever you ask.
- Short repair games (a board, a rope brace, a patch, the helm), Squawks's
  seven new feathers (and their loss), the beard REFRESHED, the yellow wake,
  and tomorrow's forecast: 700%.
- Three new music tracks (a weary morning, Shark Duty, the frenzy), night
  and frenzy ambience, and 24 new sound effects, all synthesised in code.

See [docs/STORY_PHASE4.md](docs/STORY_PHASE4.md) for the flow, flags and
systems.

## What's in Story Phase 5

*What Does the Grand Stenchmaster Actually Do?* The morning after the 700%
forecast, the ship is being eaten and one man is sitting in a chair, facing a
humming lump under a sheet.

- **Five chapters** (20 to 24) and **six quests**: *Another Terrible Day*,
  *Remember Squawks*, *What Do You Actually Do?*, *The Grand Stenchmaster's
  Office*, *Dressed for Disaster*, *One Useful Thing*.
- **The Stenchmaster Entertainment System**: an impossible television built
  from ship junk, at the Grand Stenchmaster's station. Work it yourself:
  power, six channels (static, impossible weather, a man peeling potatoes, a
  fish, a man arguing with a turnip, whispers), the wiring ("I recognise none
  of this."), the power source ("And yet."), and a slap when it misbehaves.
- **THE GRAND STENCHMASTER SUIT**, with a fanfare, a tour and five medals
  (one is a bottle cap). The sash is part of it now.
- **Squawks, fully bald**, wrapped up in his basket, still furious. The crew
  panic when the bell goes, and remember why.
- **Shark Duty** with the Grand Stenchmaster heckling from his chair
  ("Excellent shark repulsion!" "WE KNOW!"), the Center interrupting
  everyone's work, and the **emergency labour rule**: in a genuine emergency
  he does ONE useful thing. He'll do it on Jory's optional shift too.
- New CRT sounds, a self-important fanfare and a short ceremonial theme, all
  synthesised in code; Pete has a peg leg now.

See [docs/STORY_PHASE5.md](docs/STORY_PHASE5.md) for the flow, flags and
systems.

## Project layout

```
index.html              page shell (canvas is scaled in integer steps)
data/                   ALL game content as JSON (see docs/CONTENT_GUIDE.md)
src/
  main.js               creates the App and the Phaser game
  app/                  App: shared services (content, input, audio, saves...)
  config/               constants (screen size, slots, stat keys...)
  core/                 EventBus, seeded Rng, small utilities
  content/              content loading, registries and validation
  systems/              engine-independent rules: story, quests, inventory,
                        party, effects, battle engine, scripts, saves, settings
  maps/                 ASCII map compiler + BFS pathfinding
  art/                  procedural pixel art (palette, painters, font, UI)
  audio/                synthesizer (music/SFX/ambience) + Web Audio playback
  platform/             keyboard/gamepad input, storage, display scaling
  phaser/               bridge from generated art to Phaser textures
  scenes/               Boot, Title, World, Battle, Menu, GameOver, Overlay
  world/, entities/     map rendering, actors, NPC brains, field enemies
  battle/               battle presentation: battler views, HUD, timing presenters
  ui/                   text, windows, list menus, dialogue box, menu pages
  debug/                F2 overlay and E2E test hooks (dev builds only)
tests/                  Vitest unit tests
e2e/                    Playwright end-to-end tests and the shared game driver
tools/                  art preview page, play-script runner, asset exporter
docs/                   ARCHITECTURE, CONTENT_GUIDE, RETRO_PORT_NOTES
```

The key rule: **`systems/`, `content/`, `maps/`, `art/` and `audio/synth` never
import Phaser.** Game rules and content can be tested in Node and ported to
another engine; Phaser only draws, plays and reads input. See
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

### Assets

There is no binary asset folder. Art is painted into RGBA buffers by the
modules in `src/art/` (palette-driven templates for characters, parametric
portraits, tile and prop painters) and uploaded as textures during boot. Music
and sound effects are rendered by the pure-JS synthesizer in `src/audio/synth`
from note data in `data/audio/`. `npm run export` writes everything out as PNG
sprite sheets (with frame JSON) if you want to look at, trace or port them.

## Adding content

Content is data. Adding a new area or chapter means adding JSON files; no
existing chapter's code or data needs to change. Everything is validated at
startup (and by `npm run validate`): broken references stop development builds
with an on-screen list of errors.

- **NPC** — add an appearance (`data/appearances/`), a portrait
  (`data/portraits/`), the NPC (`data/npcs/`: name, behaviour, dialogue
  selectors) and place it on a map as an `npc` object.
- **Dialogue** — add scripts to any file under `data/dialogue/`. Lines are
  written as `"speaker[expression]: text"`; branches, choices, conditions,
  flags, items, quests and cutscene commands are plain JSON steps.
- **Quest** — add it to `data/quests/`. Objectives (`talk`, `inspect`,
  `visit`, `defeat`, `obtain`, `event`, `flag`, `manual`) progress by
  themselves from game events.
- **Item / equipment** — add it to `data/items/` (`consumable`, `key`,
  `equipment`); shops list item ids in `data/shops/`.
- **Enemy** — stats, abilities and AI in `data/enemies/`, abilities in
  `data/abilities/`, an encounter in `data/encounters/`, and (for new art) a
  painter in `src/art/enemies/enemyPainters.js`.
- **Map** — an ASCII layout with a legend, props and objects in `data/maps/`;
  warps link maps by id and spawn point.

Step-by-step formats and examples: [docs/CONTENT_GUIDE.md](docs/CONTENT_GUIDE.md).

## Saves

Saves are JSON records in `localStorage` (`captain-stinkbeard.save.1..3` and
`.save.auto`). Each record carries a format tag, a **schema version**, a
checksum of the state and a display summary. Corrupt, tampered or
newer-version saves are reported in the slot list instead of crashing; older
versions pass through the migration table in `src/systems/save/migrations.js`.
The game autosaves on entering a map and after battles. If storage is
unavailable (private browsing), the game runs with in-memory saves.

## Debug tools (development builds)

Press **F2** in `npm run dev`:

- **Info** — FPS, scenes, map and coordinates, current chapter, fume exposure,
  the captain's name, Garrick's title, the shark level, logbook progress,
  where the Dead Center is, Shark Duty,
  what each connected controller reports, content error count, story flags
- **Story** — start a fresh game at any point of the story (presets from
  `data/debug/presets.json`: Prologue complete, Garrick Arrival, Galley Lunch,
  Pre-Treasure Blast, Post-Blast, Squawks Rescue, Contaminated Treasure,
  Garrick Trial, Frigate Encounter, Phase 2 Complete, the twelve Phase 3
  points from Phase 3 Start to Phase 3 Complete, the eighteen Phase 4
  points from Phase 4 Start to Phase 4 Complete, and the eleven Phase 5
  points from Phase 5 Start to Phase 5 Complete)
- **Warp** — teleport to any spawn point on any map
- **Flags** — view and toggle every declared story flag
- **Quests** — start, advance, complete or reset any quest
- **Items** — give any item or +100 gold
- **Party** — heal, set HP to 1, level up, grant XP, reset level
- **Battle** — start any encounter (including test encounters)
- **Tools** — collision view, trigger/warp view, noclip, fume immunity, clear
  fume exposure, automatic perfect timed hits, info HUD, reload the current
  map, autosave now

Release builds (`npm run build`) contain none of this: the code paths are
compiled out and the debug chunks are dropped. Set `VITE_ENABLE_DEBUG=true` to
build with the overlay.

`tools/art-preview.html` (open `http://localhost:5173/tools/art-preview.html`)
shows every generated sprite; `tools/play.mjs` runs small play scripts against
the dev server and takes screenshots (`preset <id>` jumps to a story preset,
`skipshot <name>` saves a screenshot of every dialogue line, `duty <expr>`
plays Shark Duty until a condition holds).
